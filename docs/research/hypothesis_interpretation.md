# 假设检验结果解释预案

> 预先规划 H1-H4 的各种可能结果与论文响应，避免数据到达时措手不及。

## H1 物理约束价值（TST vs noPhysics，同种子配对）

**判据**：TTE/SOC/SOH 的 pinball/CRPS + MAE + 物理自洽误差。

| 结果 | 论文响应 |
|------|---------|
| TST 概率指标显著更优 | 主卖点成立：物理一致性正则提升概率精度与校准 |
| 指标相当但物理自洽误差更低 | 弱主张：物理约束无害且保证自洽性（H4 主打） |
| TST 更差 | 重新审视 λ 与损失形式；考虑改为物理后验/共形约束；或弱化 H1 主打组合新颖性 |

**预判**：物理损失只约束中位数，对 pinball/校准的直接影响有限；更可能体现在物理自洽误差（H4）与 MAE。若 H1 在概率指标上不显著，论文重心转向"H4 物理自洽 + H2 有序 + 联合概率"的组合贡献。

## H2 有序头价值（TST vs unordered，后置排序）

**判据**：ECE、PICP、crossing 数量。

| 结果 | 论文响应 |
|------|---------|
| TST ECE 更低 / PICP 更接近 0.9 | 有序头通过构造保证 + 无 crossing 改善校准 |
| 两者相当 | 有序头价值=无 crossing 保证（论文论证构造优势）+ 计算简单 |

**预判**：unordered 后置排序会产生 crossing（同一锚点不同 level 重叠），TST 保证无 crossing。校准差异可能不大，但"构造保证"本身是卖点。

## H3 cv 加权价值（TST vs fixedW）

**判据**：按 current_cv 分层的 TTE MAE/概率指标。

| 结果 | 论文响应 |
|------|---------|
| TST 在高 cv 段更好 | cv 加权论点成立 |
| 两者相当 | 物理公式在高 cv 仍准确（已核实 0.45% 误差），cv 加权无害但非必要；弱化 H3，强调设计合理性 |
| TST 更差 | 移除 cv 加权，论文不主张 H3 |

**预判（重要）**：此前核实物理公式在高 cv 段依然准确（0.45%），故 cv 加权"在高变异时降低物理约束"可能不必要。**H3 可能不显著**——论文需如实报告并调整。

## H4 物理自洽性（TST vs noPhysics 的 physics error）

**判据**：`|log_tte_med − log1p(soc·soh·q_ref/i_eff·3600)|` 在 test 上的均值。

| 结果 | 论文响应 |
|------|---------|
| TST 显著更低 | H4 核心成立：物理损失使预测自洽 |
| 相当 | 物理损失未改善自洽（模型本身能学会关系）；弱化 H4 |
| TST 更高 | 物理损失过拟合训练自洽、泛化失败；需调整 λ |

**预判**：main seed0 的 physics error=0.37（log1p 单位），待对比 noPhysics。若 noPhysics ~0.5+，H4 成立。

## 校准问题（所有配置共通）

- 若所有配置 PICP<0.9：报告 raw + 重校准（val 拟合）两种数字。
- 论文校准节需如实呈现可靠性图 + ECE + PICP，并用重校准后的 PICP≈0.9 作为校准后指标。
- 若重校准后 TST 仍优于基线，则校准处理不改变结论方向。

## 决策矩阵

数据到达后按此流程：
1. `scripts/verify_results.py` 复核每个 run（PASS 才算数）。
2. `scripts/aggregate_results.py` 生成聚合表。
3. `scripts/analyze_hypotheses.py` 计算 H1-H4 配对统计。
4. 对照本预案确定论文主张。
5. 若需重校准最终数字 → 重跑关键配置（带 checkpoint）→ `scripts/recalibrate_run.py`。
